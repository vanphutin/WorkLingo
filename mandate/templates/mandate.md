# Proposal narrative

Use this body alongside the JSON metadata template; the CLI writes frontmatter and filename.

## Analysis

Expected behavior, observed fact, exact environment/revision/date, reproduction or source citation.
Separate verified observation from inference.

## Value and alternatives

Who benefits, what measurable outcome improves, smallest option, alternatives and cost of doing nothing.
Identify conceptual overlaps with existing items and roadmap work before capture.

## Unknowns and dependencies

What is untested, scope exclusions, prerequisite work, qualified content/calibration reviewer if needed.

## Implementation and verification proposal

Affected boundaries, acceptance checks, compatibility, data/version invariants, rollback.
This is a proposal; link an approved spec/plan before moving to implementing.

## Authorization

Describe human decision scope only when actually authorized; default none. Scope changes invalidate
prior approval. Do not copy audit authorization into implementation approval.
