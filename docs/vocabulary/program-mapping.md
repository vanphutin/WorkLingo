# Program mapping

CEFR difficulty evidence, topic membership and program inclusion are independent.
The existing catalog uses beginner (Foundation), intermediate, toeic and ielts;
there is no separate persisted Basic slug to assume or automatically create.
Read actual IDs through the bounded options endpoint before assignment.

Foundation vocabulary is a reviewed subset, not every A1 source item. Basic
communication can use curated A1/A2 collections without inventing a program ID.
Intermediate collections can combine suitable A2/B1/B2 senses. TOEIC and IELTS
membership requires a reason, skills, priority and receptive/productive goal.
Neither CEFR nor domain membership establishes official exam relevance, an ETS
license, a TOEIC score range or an IELTS band.

Assignments reference versioned collection members, preserving the exact selected
sense and membership order. A collection can serve several real programs without
duplicating its lexical entries. Curriculum bindings pin an explicit published
version to one target; they do not rewrite completed lessons or learning history.
