# Bilingual topic catalog and authoring mapping

User requests many topics populated in the system and checks whether lesson entry is mapped. Implement 150 curated topic categories (not lessons/questions), with Vietnamese primary names, English names and explicit aliases sharing a group ID. Existing mapping is stable by group ID but only exposed in the separate group workspace; integrate it into authoring.

Decisions delegated to builder:
- Extend Group with `nameEn` and `aliases` (optional in wire contracts for backward compatibility), nullable unique `catalogKey` for repeatable curated imports. Register every name/alias in a unique indexed table, group FK cascade. Normalize NFKC, case and whitespace; SQL migration backfills old normalized names. Known spelling alias `restaurent` belongs to Restaurant. Do not automatically merge existing distinct groups.
- Create/update atomically reserve all names under existing taxonomy lock. An alias belonging to another group yields 409. Clearing/replacing aliases releases old names. Existing clients omitting new fields preserve metadata on update. Learner group response exposes optional English name; not aliases/catalog keys.
- Curated seed `seedIntermediateTopicCatalog(database)` consumes `intermediateTopicCatalog: readonly {key,name,nameEn,aliases,description}[]` from `apps/api/src/intermediate-topics/topic-catalog.ts`. Idempotent, preserves IDs, custom names/descriptions, existing memberships and explicit edits on reruns. Reuse a single unambiguous matching group by registered names. If multiple groups match, report skipped conflict; never merge. Return `{created,reused,skipped}` counts and conflict identifiers. Seed only these categories locally after backup/migration; never run the broad curriculum seed.
- `ContentImportDto` gets optional `topicGroupId` and `topicGroupRevision`. Create input adds optional `topicGroupId:uuid` (no null needed; omit means ungrouped). Backend validates Intermediate topic source/group and stores assignment/revision in the same creation transaction. `ContentImportsService.create(actor,source,topicGroupId?)`; old callers remain supported. Main owns web API client signature `(rawSource, topicGroupId?)`.
- A separate `TopicGroupField` loads catalog, searches names/English/aliases, selects a stable ID on new lessons and sends it with create. Saved lessons use the existing assignment API immediately, preserving source unsaved edits and duration approval; handle revision conflict explicitly. Failure loading categories must not prevent existing ungrouped lesson authoring. JSON review keeps chosen topic; JSON text is lesson content, taxonomy selection is separate.
- Category workspace gains editable English/aliases fields and topic search for 150 entries. Learner names follow UI locale with primary-name fallback.
- Latest user correction: all topic labels in admin menus, headings and assignment selectors also follow the UI locale; never concatenate both names in display labels. Search still matches all registered names. Admin name-edit fields remain separate. Scroll rows must keep their natural wrapped height.
